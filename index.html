    若您希望在審核通過後，直接在網頁上一鍵自動推送到 YouTube 頻道：
    1. 前往 Google Cloud Console 啟用 YouTube Data API v3。
    2. 建立 OAuth 2.0 Client ID (桌面應用程式 Desktop App)。
    3. 下載 JSON 憑證，並重命名為 client_secrets.json 放進此專案根目錄。
    4. 終端機安裝套件：.venv/bin/pip install google-api-python-client google-auth-oauthlib
    5. 審核通過後，點擊「🚀 立即上傳至 YouTube」即會全自動進行！
